На устройствах с мышью фото увеличивается в 2,5 раза и следует за курсором. Уход курсора или начало перетаскивания возвращают обычный вид. Движение мыши больше не переключает снимки; миниатюры, свайпы и колёсико сохранены.

Кнопка лупы открывает выбранный снимок в окне. Доступны увеличение 2×, прокрутка мышью/пальцем, уменьшение, закрытие, Escape и возврат фокуса. Области нажатия — 44 × 44 px. Сенсорные устройства не включают hover-увеличение.

## Проверки

Сборка и отдельная проверка TypeScript прошли. В Chromium проверены увеличение, слежение за курсором, возврат масштаба, неизменность квадратной области и маски JPEG, клавиатура, Escape/фокус, reduced motion, touch-просмотр и настоящая прокрутка пальцем на 320/390 px.

В текущем публичном каталоге нет товаров с несколькими фото. Переключение миниатюрами, колёсиком и настоящим свайпом проверено на копии браузерного ответа с двумя существующими фотографиями; отсутствие фото — на пустой копии ответа. Реальные данные и API не изменялись. Отчёт локальной сборки: `/workspace/scratch/valore-gallery-zoom/report.json`.

Фотографии, данные товаров, API, корзина, первый экран и оформление других разделов не изменяются. Публикация выполняется существующим workflow только для frontend `landing`.

## Возврат

Для отмены только этой функции на актуальной чистой `main` создают новый коммит:

```bash
git revert c1ff735d6f3765d4b748fc69f2d5eaf85c9dd4c4
npm run build
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

После проверки отправляют коммит восстановления и публикуют его полный SHA. Старый SHA не подают в workflow, который требует продвижение истории вперёд. Первый экран с кухней и предшествующий мобильный редизайн остаются.
