# Мобильная версия Valore Milano — 9 октября 2026

Изменения подготовлены и проверены локально поверх `811169777aef4d439732c06748f5feb055e1fa1f`. Владелец разрешил публикацию 9 октября 2026 года. Для мобильной доработки выделен отдельный коммит; версия перед ней сохраняется тегом `before-mobile-2026-10-09`, новая — `valore-mobile-2026-10-09`. Фактический результат публикации подтверждает [Production website / Actions](https://github.com/Ashima-alt/landing/actions/workflows/production-deploy.yml). Карта предыдущего опубликованного редизайна в `releases/2026-10-09-redesign.md` сохраняет своё историческое значение.

## Что создавало проблему

1. Каталог и похожие товары использовали `grid-cols-1 sm:grid-cols-2`, поэтому ниже 640 px получалась одна крупная карточка.
2. У главной было отдельное правило `@media (max-width: 479px)`, возвращавшее витрину в одну колонку.
3. Мобильные значения `--header-height` и `--section-space` находились внутри `@layer components`, а исходные значения — вне слоя. Исходный `:root` выигрывал: браузер оставлял шапку 88 px и более крупные отступы даже на телефоне.
4. Квадратная фотография первого экрана занимала всю ширину; заголовок оставался 44 px. Эмблема использовала высокую плашку 5:4. Подвал становился одной длинной колонкой.

## Новая мобильная компоновка

- Каталог, витрина главной и похожие товары: две колонки, `minmax(0, 1fr)`, промежутки 12 px между колонками и 24 px между рядами.
- Область фотографии: квадрат, `object-fit: contain`, центрирование, прежний внутренний отступ 12 px. Сами фотографии и прежняя маска края JPEG не изменены.
- Названия: 14 px / 1,4, одинаковая область на три строки. Длинные слова переносятся. Полное название сохраняется в данных, на странице товара и в доступном имени ссылки. Артикулы компактные; материал и размер занимают фиксированную область на две строки.
- Шапка: 64 px. Кнопки открытия/закрытия меню и закрытия фильтров — 44 × 44 px, строки фильтров — от 44 px. Основные кнопки — от 48 px.
- Первый экран: фотография ограничена 224–280 px, остаётся полностью видимой; заголовок 32–40 px, отдельные мобильные расстояния. Исходная фотография сохранена.
- Заголовки разделов: 26–30 px; основной текст: 15 px / 1,65. Токен межсекционных отступов: 40 px на телефоне и 56 px на планшете.
- История/философия: компактная горизонтальная плашка эмблемы 136–156 px, название принципа и его описание стоят рядом. Текст и геометрия официального знака сохранены.
- Подвал: описание бренда сверху, затем навигация и контакты рядом на 360–767 px. На 320 px контакты остаются в отдельной колонке для читаемости. Контактные заглушки сохранены.
- Страница товара: уменьшены отступы, заголовок 28 px, компактнее характеристики и похожие товары. Саму галерею не меняли.

## Как вернуть мобильную версию

Предыдущая версия: `before-mobile-2026-10-09` → `811169777aef4d439732c06748f5feb055e1fa1f`. В ней остаётся графитовый редизайн; отменяется только последующая мобильная доработка.

Для полного возврата на актуальной чистой `main` создают новый коммит:

```bash
git revert valore-mobile-2026-10-09
npm run build
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

После проверки новый коммит отправляют в `main` и запускают существующий workflow с `mode: deploy` и его полным SHA. Workflow допускает продвижение вперёд, поэтому старый SHA не подают как цель деплоя.

Для точечной доработки используют таблицу файлов выше: первый экран — `hero.css` и `hero-section.tsx`; шапка — `header.css` и `header.tsx`; подвал — `footer.css` и `footer.tsx`; блок бренда — `brand.css`. Файлы `globals.css` и `product-card.css` общие для нескольких разделов: их не отменяют целиком ради одного блока. При необходимости вернуть часть к исходному виду сравнивают соответствующие файлы с `before-mobile-2026-10-09` и сохраняют изменения новым коммитом, затем проверяют зависимые разделы.

Публикация использует существующий workflow: сборка выполняется до переключения сайта; при ошибке переключения предусмотрен возврат прежней сборки. Перезапускается только frontend `landing` через PM2 пользователя `deploy`; API и данные каталога не обновляются.
